# 关键词战略与搜索意图页面映射说明 (Keyword Map)

本文档系统阐述本项目在 Google / Bing 自然搜索中的关键词聚类、意图映射、合规隔离与落地页规划。

## 1. 核心商业与推荐意图集群

- **主推落地页**：`/recommendations/`（综合推荐）、`/recommendations/value/`（性价比）、`/recommendations/clash/`（Clash推荐）、`/rankings/`（排序说明）
- **核心词群**：性价比机场、机场推荐 clash、便宜机场、低价机场、稳定机场、专线机场、顶级机场（指标化解读）
- **转化路径**：解决选型焦虑 -> 展示前四名固定服务（全球云、飞猫云、暮光加速、微风网络）对比卡片 -> 引导查看当前套餐与结算页

## 2. 节点与线路选型集群

- **主推落地页**：`/nodes/`、`/service/`
- **核心词群**：机场节点、节点推荐、vpn 节点、香港/日本/新加坡/美国节点选择、倍率与延迟

## 3. 客户端与协议知识集群

- **主推落地页**：`/devices/`、`/start-here/`
- **核心词群**：Clash 订阅、Trojan 协议、SSR、SS 协议、Shadowrocket、sing-box
- **定位**：中立技术概念科普、兼容性与隐私配置指南，不写规避或滥用教程

## 4. 常见问题与口语长尾词集群 (FAQ 100)

- **主推落地页**：`/faq/`
- **核心词群**：网络梯子服务选择、“梯子”中立术语解析、连接失败排查、退款规则、多设备并发、流量用尽处理

## 5. 合规与参考源隔离规则

- 严禁将参考博客（如二毛博客、猫梦博客等）名称或外链公开写入页面。
- 严禁使用“翻墙”“100%保证可用”“全网第一”等违规表达。
